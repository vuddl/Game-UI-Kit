---
name: gui-mockup
description: Assemble game UI mockups for a screen or all, or adjust them. Runs the game-ui-kit skill's `mockup` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `mockup` command, treating everything the user typed after `$gui-mockup` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
