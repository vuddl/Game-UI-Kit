---
name: gui-flow
description: Build the clickable game UI flow demo. Runs the game-ui-kit skill's `flow` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `flow` command, treating everything the user typed after `$gui-flow` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
