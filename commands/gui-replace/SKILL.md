---
name: gui-replace
description: Regenerate one game UI sprite and update its screens. Runs the game-ui-kit skill's `replace` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `replace` command, treating everything the user typed after `$gui-replace` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
