---
name: gui-tone
description: Show or change where the game UI tone comes from. Runs the game-ui-kit skill's `tone` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `tone` command, treating everything the user typed after `$gui-tone` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
