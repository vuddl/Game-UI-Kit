---
name: gui-info
description: Show all game UI kit commands and the current kit's status. Runs the game-ui-kit skill's `info` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `info` command, treating everything the user typed after `$gui-info` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
