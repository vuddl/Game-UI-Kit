---
name: gui-asset
description: Generate the game UI sprites a confirmed wireframe needs. Runs the game-ui-kit skill's `asset` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `asset` command, treating everything the user typed after `$gui-asset` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
