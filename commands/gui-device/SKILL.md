---
name: gui-device
description: Preview game UI screens on other aspect ratios. Runs the game-ui-kit skill's `device` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `device` command, treating everything the user typed after `$gui-device` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
