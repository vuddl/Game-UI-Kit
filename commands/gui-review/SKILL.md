---
name: gui-review
description: Critique a game UI screen and suggest fixes. Runs the game-ui-kit skill's `review` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `review` command, treating everything the user typed after `$gui-review` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
