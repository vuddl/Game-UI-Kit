---
name: gui-export
description: Export confirmed game UI screens as editable PSD or a Unity mapping. Runs the game-ui-kit skill's `export` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `export` command, treating everything the user typed after `$gui-export` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
