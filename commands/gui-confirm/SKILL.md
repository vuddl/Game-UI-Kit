---
name: gui-confirm
description: Confirm a game UI wireframe or a screen's mockup. Runs the game-ui-kit skill's `confirm` command.
---

Read the `game-ui-kit` skill's `SKILL.md` in the Codex skills folder, then run its `confirm` command, treating everything the user typed after `$gui-confirm` as that command's arguments. If `game-ui-kit` is not installed, say so and stop.
